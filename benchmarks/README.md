# Benchmark artifacts

Files in this directory are generated by `make benchmark` (or individual CLI
commands). They are machine-readable so regressions can be compared over time.

| File | Contents |
|---|---|
| `device.json` | CPU/backend capabilities from `vnpu-cli info --json` |
| `gemm.json` | GEMM matrix across shapes, dtypes and compute units |
| `sherlock-trace.json` | Chrome Trace for the GEMM benchmark |
| `autotune-f32.json` | best F32 tile/unit for 512³ |
| `autotune-i8.json` | best INT8 tile/unit for 512³ |
| `llm-block.json` | synthetic transformer block prefill/decode results |
| `llm-trace.json` | Chrome Trace for the transformer block |
| `cluster-demo.txt` | two-node loopback cluster result and stats |
| `specdemo.txt` | distributed draft/verifier demo output |
| `autotune-recommendations.json` | optional output from `scripts/autotune_all.py` |

Regenerate:

```bash
make clean
make -j$(nproc)
make benchmark
python3 scripts/trace_report.py benchmarks/sherlock-trace.json
python3 scripts/autotune_all.py 512x512x512 1024x1024x1024
```

Interim files such as `gemm2.json`, `full-trace.json` or `test-trace*.json`
may appear during development; they are safe to delete and are ignored by git.
